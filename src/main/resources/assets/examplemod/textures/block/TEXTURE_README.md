# Texture Placeholder

This directory (`src/main/resources/assets/examplemod/textures/block/`) should contain the texture file:
- `example_block.png` - A 16x16 pixel PNG texture for the custom block

## Creating a Texture

You can create your own texture using:
1. Any image editor (GIMP, Photoshop, Paint.NET, etc.)
2. Online Minecraft texture creators
3. Copy and modify textures from Minecraft's default resources

The texture should be:
- 16x16 pixels (standard Minecraft block texture size)
- PNG format
- Named `example_block.png`

Place the texture file in this directory to complete the block model.
